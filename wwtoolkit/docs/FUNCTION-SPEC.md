# 鸣潮矩阵配队工具箱（wwtoolkit）功能与信息规格

> 版本：2026-11-22 · 依据真实页面 DOM 逐项核对
> 用途：① 设计/原型的功能基线（功能不增不减）；② 后续改版与验收的对照清单。
> 页面地址：`/waves/toolkit/`（gsuid_core 插件挂载，本地 :8765）

---

## 0. 产品定位与核心规则

「矩阵铺分」是《鸣潮》周期性活动：玩家提交 **20 支队伍**（可扩到 24 支），每队 **3 名角色**；每名角色在本期有 **1 或 2 点体力**，体力 = 该角色**能进几支队伍**（2 点体力的角色可以同时出现在两支队伍，1 点只能出现一次；本期「额外疲劳值」角色为 2 点）。

每支队伍在游戏内打出分数后回填；分数按「出战顺序」逐段铺到当期 5 个首领目标（4 只 boss + 1 个宝箱）的血条上，宝箱 +1000 会自动从可用分里扣除。工具的目标是：**在体力约束下排出 20～24 支队、录入分数、核对血条分配，并保存多套方案**。

技术边界（原型同样遵守）：
- 单页 HTML（原生 HTML/CSS/JS），顶部固定 Header + 导航栏，内容区各区块内部独立滚动，整页不出现纵向滚动条。
- 双主题 `data-theme="light" | "dark"`，切换后持久化（localStorage `mc-toolkit-theme`）。
- 视图用页签 + hash（`#pair` / `#matrix` / `#archive`）切换，导航栏下拉框与页签双向同步。
- 桌面优先：1600×900、1920×1080 下 20 支队要能一屏铺满（3 列 × 7 行）。
- 中文排版；数字用等宽字体。

## 2. 配队页（pair）

布局：左栏「角色池」（固定宽度，独立滚动）+ 右栏「队伍编成」（占满剩余，独立滚动）。

### 2.1 左栏 角色池

**头部（rail-head）**
- 标题 `角色池` + 筛选后角色数 `29`（`#poolShown`）
- 副行 `已上阵 3`（`#usedCount`）

**搜索与筛选**
| 元素 | 说明 |
|---|---|
| 搜索框 | 占位「搜索角色…」，输入实时过滤；有内容时显示清除按钮 `✕` |
| 属性 chip | `全部` · `未编队`（快捷筛选：只显示**还有剩余体力**的角色）· `气动` · `热熔` · `冷凝` · `导电` · `衍射` · `湮灭` |
| 排序下拉 `sortSel` | `按评分` / `按等级` / `按共鸣链` / `按名称` |
| 结果计数 | `筛选结果 29`（`#poolShown2`） |

**角色卡（网格 3 列）**，每张显示：
| 区域 | 显示信息 |
|---|---|
| 立绘 | 角色半身像铺满卡片（`/api/avatar/{id}`） |
| 左上角 | 体力 `⚡N`（剩余可进队伍次数；用尽时置 0 并整体降透明度） |
| 右上角 | 共鸣链徽章（`零链`/`一链`/`二链`/`三链`…，按链数配色） |

### 2.2 右栏 队伍编成

**工具栏（teams-bar）**
- 标题 `队伍编成` + 英文副标 `SQUADS`
- 说明 `共 20 / 24 队 · 点击池内角色后点空位添加，也可直接拖拽`（`#teamCount`）
- 按钮（右对齐）：`同步矩阵数据` · `＋ 新建队伍` · `清空` · `撤销` · `攻略预设` · `⚙ 预设` · `矩阵铺分 →`

**队伍卡网格（3 列，20～24 张）**
每张队伍卡：
| 区域 | 显示信息 |
|---|---|
| 头行（tm-h） | 序号 `01` + `队伍 1` + 已填槽数 `3/3` + 右侧 `⌫`（清空该队） |
| 槽位（tm-slots） | 3 个；已填显示成员卡，空槽显示虚线框 `＋` + 文案 `点角色放入` |

**成员卡（mb，竖排，头像铺满 + 底部玻璃信息浮层）**
| 区域 | 显示信息 |
|---|---|
| 立绘 | 角色像铺满整格 |
| 左上 | 共鸣链 pill（`二链` 等，按链数配色） |
| 右上 | 等级 `Lv.90` |
| 头像下沿 | 双模态角色：当前模态名小条 |
| 底部浮层左列（3 行） | ① 名字行：属性图标 + 角色名 ② 武器行：武器图标 + 武器名 + `Lv.90` + 精炼 `★N`（`weapon_reson`） ③ 技能行：5 个菱形技能图标 + 各自等级（过滤掉延奏/谐度破坏后剩 5 个） |
| 浮层右侧（nm-rt） | 评分块：分数（如 `172.63`）+ 评分等级色长条；无声骸数据时显示灰条 + 横线 |
| 右上角 `✕` | 从该槽移出 |

**交互**
| 操作 | 行为 |
|---|---|
| 点池卡 → 点空槽 | 放入该角色（校验剩余体力；预设命中则整队带入） |
| 点空槽（未选角色） | 进入「连点补位」模式：之后每点一个角色就补进该队下一个空位，补满自动退出；目标队伍高亮 |
| 拖拽 | 池卡 → 槽位（放入）；槽位 → 槽位（换位/换队）；拖拽把手调整顺序；拖拽时显示插入指示 |
| 撤销 / 清空 | 撤销一步操作 / 清空全部编队（带确认） |
| 体力规则 | 剩余体力 ≤ 0 的角色不可再放入，点击提示「XX 体力已用尽」 |
| 队伍上限 | 最少 20 支，最多 24 支（`＋ 新建队伍` 到 24 后禁用） |

## 6. 全局交互与状态

| 能力 | 说明 |
|---|---|
| 自动保存 | 任意改动后 320ms 防抖存后端；右上角显示 `保存中…` → `已保存` |
| 撤销 | 配队页 `撤销`（单步回退：编队、分数、buff 选择、顺序） |
| 体力语义 | 体力 = 能进几支队；2 点体力角色可同时出现在 2 支队伍；剩余 0 时锁灰 |
| 队伍上限 | 20～24 支 |
| 主题 | `data-theme` light/dark，持久化 |
| 视图 | `#pair` / `#matrix` / `#archive`，页签与下拉框同步 |
| 预设带入 | 从角色池点/拖预设内任意成员 → 整队带入（缺角色跳过、体力不足跳过），toast `已按「XX」配队` |
| 同步矩阵 | 调游戏接口拿账号实际已打编队 → 覆盖编队（带分数与 buff），有变动先确认 |
| Toast | 底部居中，2.2 秒淡出 |
| 确认框 | 同步矩阵、载入/覆盖方案、清空编队、删除方案 |
| 空态 | 无角色数据 → 提示发 `ww刷新面板`；未绑定 → 提示 `ww绑定 UID` |
